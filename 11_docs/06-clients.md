# Purpose

Manage complete customer information and lifetime relationship.

One client can have multiple projects throughout many years.

- Edit Client

# Business Rules

- Mobile number should be unique where possible.
- One client can have multiple bookings.
- Client cannot be permanently deleted.
- Archive only.
- Client history must remain permanently searchable.
