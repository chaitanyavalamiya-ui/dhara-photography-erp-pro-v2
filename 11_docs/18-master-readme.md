# Project Vision

Build a modern, scalable and commercial-grade ERP system for photography studios.

The ERP must support complete business operations from Lead Management to Project Archive without hardcoded business logic.

# Codex Instructions

Before generating code:

1. Read every document inside the 11_docs folder.
2. Follow every documented business rule.
3. Never hardcode prices, packages, services or equipment.
4. Use Settings as the source of configurable values.
5. Build production-quality code.
6. Maintain modular architecture.
7. Preserve database relationships.
