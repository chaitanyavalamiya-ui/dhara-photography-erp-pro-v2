# Purpose

The Dashboard is the control center of Dhara Photography ERP Pro V2.
It provides real-time business insights, alerts and quick actions.

- Real-time Overview
- Today's Bookings

- Calendar
- Staff Status
- Equipment Status
- Financial Summary
- Pending Tasks
- Notifications
- Quick Actions
