1. INTRODUCTION
============================================================

This document defines the complete software architecture of Dhara
Photography ERP Platform.

It acts as the technical blueprint for developers, architects and AI
development tools including Codex.

Every software module, API, workflow and database structure must follow the
architecture described in this document.

No implementation should violate these architectural principles.

3. SYSTEM OVERVIEW
============================================================

Dhara Photography ERP Platform consists of multiple independent modules.

Every module communicates through backend APIs.

All business data is stored inside PostgreSQL.

Digital files are stored separately inside structured file storage.

Authentication, authorization and audit logging are centralized.

The architecture follows modular design principles to ensure long-term
maintainability.
